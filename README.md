# Autonomous Robot Software Platform

Software platform designed for a multi-task robot built with LEGO systems and powered by processors such as Raspberry Pi or ARM7. The system ingests sensory data, processes decision logic, executes motor actions, and validates functionalities through simulation animations.

## Features & Functionalities
- **Color Recognition & Line Following:** Tracks color lines to simulate autonomous driverless vehicle navigation.
- **Obstacle Avoidance:** Detects and maneuvers around obstacles in real time.
- **Four-Wall Navigation:** Navigates within bounded four-wall environments without collisions.
- **Object Pick-Up & Drop:** Pick-up and drop-off object manipulation within confined areas.
- **Voice Recognition:** Ingests and responds to voice commands.
- **Automated & Time-Controlled Execution:** Fully automated operations managed with precise time controls.
- **Processor-Targeted Logic:** Built for Raspberry Pi, ARM, or similar microprocessors.
